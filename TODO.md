What it is

New wordmark variant on Logo — PORTAGE, the rules, and PLACE lifted verbatim from lockup.svg, cropped to a tight viewBox of 62.5 247 429 109.9. I took those bounds from getBBox() in a browser rather than eyeballing the crop: the icon sits inset from the wordmark's left edge, so cropping by eye would have misaligned it. No path data was altered.

Both parts scale from one variable, so they can't drift apart:

┌───────────┬───────┬────────────────┬───────┬───────────────┐
│           │ icon  │ wordmark block │ brand │     slack     │
├───────────┼───────┼────────────────┼───────┼───────────────┤
│ 375–639px │ 60×34 │ 133×34         │ 239px │ 60px          │
├───────────┼───────┼────────────────┼───────┼───────────────┤
│ 640px+    │ 67×38 │ 148×38         │ 261px │ 208px at 1024 │
└───────────┴───────┴────────────────┴───────┴───────────────┘

Block height is matched 1:1 to the icon, not the master's 0.814 ratio. I tried 0.814 first and measured the result: PLACE came out at a 7.9px cap and the rules at 0.84px. At 1:1 it's PLACE 9.6px, PORTAGE 21.9px, rules 1.04px. The mobile icon also went 30 → 34px for the same reason.

Accessibility is handled: the SVG is aria-hidden, and a visually-hidden "Portage Place" carries the link's accessible name — confirmed reading "Portage Place". And no duplicate ids: the header strips them, the footer keeps them for its draw animation, verified across built pages.

The two variants

I was wrong in my own preview — I estimated the rules at 0.5px. Computed properly they're 1.04px desktop / 0.93px mobile. Still sub-pixel, so the rasteriser spreads each across two rows and dims it.

Faithful — stroke scales with the block (1.04px / 0.93px).
Optical — vector-effect: non-scaling-stroke pins them at 1.25px at every size. Nothing else changes; no letterform is touched.

Measured rule brightness at 1× DPR:

┌──────────────────────────┬──────────┬─────────┐
│                          │ faithful │ optical │
├──────────────────────────┼──────────┼─────────┤
│ 1280px (rule rows 51–52) │ 133/255  │ 150/255 │
├──────────────────────────┼──────────┼─────────┤
│ 390px (rule row 48)      │ 216/255  │ 238/255 │
└──────────────────────────┴──────────┴─────────┘

At 3× DPR they're indistinguishable — the difference only exists on standard-density displays, which is most desktop monitors.

Comparisons are at /tmp/x1-cmp-390.png and /tmp/x1-cmp-1280.png (rendered at 1×, magnified 4× nearest-neighbour so you see actual pixels). 390px is where it's obvious — faithful renders the rules thin and grey, optical renders them solid at the same weight as PLACE.

One correction to something I said mid-check: I first read the 1280 comparison as "optical looks worse" and then measured it — my detector had latched onto the plaque border rather than the rules. Filtered to the rules' real 31px width, optical is brighter at both sizes.

My recommendation is optical. It's a stroke width on two straight lines, and it's the difference between the rules reading as drawn and reading as a rendering artefact.
